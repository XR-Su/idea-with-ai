# 决策速查

| 看到的情况 | 下一步 | 原因与边界 |
|---|---|---|
| 只有上级要求、模板或既有结论 | 先明确问题，访问不同现场和熟悉情况的人 | 调查可发现适用条件；权威不是事实证据。 |
| 观察很多但没有解释 | 整理材料，提出可证伪的关系，再选择安全的检验 | 不要把印象直接当成规律。 |
| 方案试行成功一次 | 检查对照、其他变化、成本和不同地点结果 | 成功一次不排除偶然或替代解释。 |
| 多个问题互相牵制 | 明确阶段，写出主次判断与证据，并设复核条件 | 主要矛盾与矛盾的主要方面不是同一概念；可存在多个关键约束。 |
| 把任何分歧都视为敌对 | 先判断各方关系、条件及可协商空间 | 原著区分矛盾和对抗；现代处理须合法且相称。 |
| 一线意见分散 | 集中分析、反馈方案、试行并再收集意见 | 试点有选择偏差，且应允许不同意见。 |
| 多地条件不同，却要求同速执行 | 先按实际基础设计不同任务与复核条件 | 不把形式一致当成实施效果一致。 |
| 只依据短期事件判断长期结局 | 比较多因素，列出不同情景与观察指标 | 历史上的阶段图和预测不是固定模板。 |
| 决策脱离执行，或报喜不报忧 | 公开议题、明确分工，报告问题和拟采取的行动 | 留出反对意见和重大问题即时反馈渠道。 |
| 目标明确但缺人、资源或方法 | 写出执行责任、资源、依赖和安全边界 | 目标不能代替实现目标的条件。 |

**溯源**：调查与实践见第一卷；反馈闭环见第三卷；报告和地区差异见第四卷。历史文本的政治和战争语境不能直接套用到现代组织。
